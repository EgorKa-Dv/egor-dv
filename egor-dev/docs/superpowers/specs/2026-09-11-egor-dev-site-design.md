# egor.dev — сайт-визитка веб-разработчика: дизайн-спецификация

Дата: 2026-09-11 · Статус: одобрено пользователем

## 1. Цель и позиционирование

Личный сайт-визитка Егора — начинающего веб-разработчика. Главная мысль: **клиент покупает не сайт, а поток клиентов**.
Сайт + вывод в поиск и на Карты + реклама в Яндекс.Директе + заявки в Telegram + аналитика.

- Заголовок первого экрана: **«Делаю сайты, которые приводят клиентов»** («приводят клиентов» — акцентным цветом).
- Аудитория: малый бизнес (локальные услуги, стройка/ремонт, эксперты, доставка), который хочет заявки, а не «просто сайт».
- Эмоция: доверие и спокойствие → синяя/голубая палитра, аккуратная типографика, честные формулировки.

### Правила честности (обязательные)
- Услуги описываются уверенно («настрою Директ», «выведу сайт в поиск») — это решение владельца.
- **Запрещено:** выдуманные отзывы, выдуманные цифры результатов («рост трафика 3x», «95+ PageSpeed у клиентов»), гарантии позиций («топ-1 за неделю»), фейковые счётчики клиентов/лет опыта, зачёркнутые «старые» цены.
- Все работы помечены плашкой **«Концепт»**; описания составляются только по реальному содержимому проектов.
- Макет Telegram-уведомления в hero подписан как «пример уведомления».
- В FAQ честно: индексация в поиске занимает 1–4 недели; рекламный бюджет оплачивает клиент напрямую Яндексу.

## 2. Технологии и структура

Статичный HTML/CSS/JS без сборки (как остальные проекты владельца), деплой на Vercel. Скрипты — классические (не ES-модули), чтобы сайт открывался и через `file://`.

```
egor-dev/
  index.html            — вся визитка
  privacy.html          — политика конфиденциальности (шаблон, 152-ФЗ)
  css/base.css          — токены, сброс, типографика, кнопки, утилиты, фон-сетка
  css/sections.css      — стили секций + адаптив
  js/config.js          — window.SITE_CONFIG: контакты-заглушки, URL сайта, id Метрики
  js/cases.js           — window.CASES: данные концепт-проектов
  js/main.js            — меню, reveal, параллакс hero, фильтр и модалка работ, FAQ, форма
  api/lead.js           — Vercel-функция: заявка → Telegram-бот
  assets/img/cases/     — скриншоты концептов (JPEG, desktop 1440×900 + mobile 390×844 @2x)
  assets/favicon.svg, assets/og.jpg
  robots.txt, sitemap.xml
  README.md             — как заменить контакты, подключить бота, задеплоить
```

Контакты (Telegram, телефон, email) — **только в `js/config.js`**; элементы с `data-contact="telegram|phone|email"` получают `href` и текст из конфига. В HTML — те же заглушки как fallback.

## 3. Визуальная система

**Схема:** смешанная — тёмные секции чередуются со светлыми.

| Токен | Значение | Назначение |
|---|---|---|
| `--d-bg` | `#0B1220` | фон тёмных секций |
| `--d-surface` / `--d-surface-2` | `#111B2E` / `#16223A` | карточки на тёмном |
| `--d-border` | `rgba(148,178,230,.14)` | обводки на тёмном |
| `--d-text` / `--d-muted` | `#E8EEF8` / `#93A3BD` | текст на тёмном |
| `--blue` | `#3B82F6` | основной акцент, кнопки |
| `--blue-light` | `#60A5FA` | акцентный текст на тёмном |
| `--cyan` | `#38BDF8` | свечения, градиенты |
| `--blue-deep` | `#1D4ED8` | акцент на светлом |
| `--l-bg` / `--l-surface` | `#F5F8FC` / `#FFFFFF` | светлые секции / карточки |
| `--l-text` / `--l-muted` / `--l-border` | `#0F172A` / `#5B6B82` / `#E2E8F2` | текст и обводки на светлом |

- **Шрифты:** Unbounded (600–800) — заголовки, широкий гротеск как в референсе; Onest (400–600) — текст. Google Fonts, `display=swap`, preconnect.
- **Эффекты:** фоновая сетка + мягкие синие свечения; появление блоков при скролле (IntersectionObserver); наклонённые «плавающие» карточки работ в hero с лёгким параллаксом от мыши; анимированный поток точек по линиям в схеме «как сайт находит клиентов»; свечение у главных кнопок. Всё отключается при `prefers-reduced-motion`.
- **Адаптив:** 1440+ / 1024 / 768 / 375. На мобильных — бургер-меню, карточки hero уходят в ряд под заголовком.

## 4. Секции (порядок, тема, содержание)

1. **Шапка** (тёмная, sticky, блюр): логотип `egor.dev` → меню: Работы, Как это работает, Цены, Процесс, Обо мне, FAQ, Контакты → кнопка «Обсудить проект».
2. **Hero** (тёмная): бейдж «Открыт для новых проектов»; H1; подзаголовок «Не просто красивая страница: сайт появится в Яндексе и на Картах, реклама приведёт людей, а заявки будут приходить вам в Telegram»; кнопки «Обсудить проект →» и «Смотреть работы»; три факта: «от 5 000 ₽», «от 3 дней», «заявки в Telegram». Вокруг — 4 наклонённых скриншота концептов. Карточка-макет Telegram-уведомления «Новая заявка с сайта · Источник: Яндекс.Директ» с подписью «пример уведомления».
3. **Как сайт находит клиентов** (`#how`, тёмная): схема «Поиск Яндекса и Google / Яндекс.Карты / Яндекс.Директ → Ваш сайт → Заявка в Telegram», под ней «Яндекс.Метрика показывает, какой канал сработал». 4 карточки-пояснения по каналам и аналитике.
4. **Для кого** (`#niches`, тёмная): 4 карточки 01–04 с тегами:
   - 01 Локальные услуги — барбершопы, салоны, автосервисы, ветклиники (Карты · Онлайн-запись · Прайс)
   - 02 Стройка и ремонт — дома, бани, потолки (Калькулятор · Галерея работ · Заявка на замер)
   - 03 Эксперты и частная практика — юристы, репетиторы, психологи (О себе · Услуги · Запись на консультацию)
   - 04 Доставка и логистика — еда, грузоперевозки (Расчёт стоимости · Заказ онлайн)
5. **Работы** (`#works`, тёмная): фильтр «Все / Услуги / Стройка / Доставка / Эксперты»; карточки со скриншотом, плашкой «Концепт», названием, нишей и строкой «что сделано для заявок». Клик → модалка: desktop- и mobile-скриншоты, описание, список «Что работает на заявки». Подпись: концепты показывают подход, реальные кейсы появятся после первых клиентов. Состав: ГРУЗЛАЙН, Бровистки, Бритва & Латунь, ТочкаДрайв, СтройДом, Дачный цех, Лапами вверх, Натяжные потолки, Рацион (если скриншоты получатся качественными; иначе исключаются).
6. **Цены** (`#prices`, светлая): «Цены без сюрпризов» + «Я начинаю, поэтому цены ниже рынка. Итог фиксируем до старта».
   - **Визитка — 5 000 ₽ · 3–5 дней:** одна страница до 5 блоков; адаптив; форма, заявки в Telegram; подключение домена и хостинга; 2 круга правок.
   - **Сайт + поиск — 9 000 ₽ · 5–7 дней · «Популярный»:** до 10 блоков; всё из «Визитки»; SEO-основа (мета-теги, скорость, sitemap); добавление в Яндекс.Вебмастер и Google Search Console; Яндекс.Метрика с целями; карточка в Яндекс.Картах.
   - **Сайт + клиенты — 15 000 ₽ · 7–10 дней:** всё из «Сайт + поиск»; запуск стартовой кампании в Яндекс.Директе; цели и UTM-метки; 2 недели сопровождения; отчёт по источникам заявок. Примечание: рекламный бюджет — отдельно, напрямую Яндексу.
   - Баннер-бонус: «Первым 5 клиентам — месяц поддержки бесплатно в обмен на честный отзыв».
   - Доп. опции (5 строк): доп. блок +500 ₽; доп. страница +1 500 ₽; калькулятор стоимости +2 000 ₽; онлайн-запись +2 000 ₽; ведение Директа 3 000 ₽/мес.
   - Оплата: 50% предоплата, 50% после приёмки.
7. **Процесс** (`#process`, тёмная): вертикальный таймлайн 01–05 — Бриф (1 день) → Структура и дизайн (1–2 дня) → Разработка (2–5 дней) → Запуск и поиск (1 день) → Реклама и отчёт (по пакету); у каждого шага — результат.
8. **Почему мне можно доверять** (`#trust`, светлая): 6 карточек — оплата 50/50; фиксированная смета; домен, хостинг, код и доступы — на клиента; 2 круга правок включены; связь напрямую со мной; промежуточные версии по ссылке.
9. **Обо мне** (`#about`, тёмная): без фото — графический блок с монограммой «Е» в синем градиенте. Текст: начинаю путь во фрилансе → беру немного проектов, цены ниже рынка, внимания больше. Строки «Связь / Подход / Инструменты». Кнопка «Обсудить проект».
10. **FAQ** (`#faq`, тёмная, аккордеон): стоимость; сроки; что нужно от клиента; когда сайт появится в поиске (честно, 1–4 недели); кто платит за рекламу; домен и хостинг; правки после запуска.
11. **CTA** (светлая секция, тёмная карточка): «Пусть сайт начнёт работать на вас» → «Оставить заявку».
12. **Контакты** (`#contacts`, тёмная): слева Telegram (плашка «быстрый ответ»), телефон, email, карточка «Бесплатная консультация: разберу ваш сайт или соцсети и подскажу, откуда брать клиентов». Справа форма (см. §5).
13. **Футер** (тёмный): логотип и описание, навигация, контакты, © 2026 egor.dev, ссылка на политику.

## 5. Форма заявки

- Поля: пакет (чипы: Визитка / Сайт + поиск / Сайт + клиенты / Пока не знаю), имя (обязательно), телефон или Telegram (обязательно), о проекте (необязательно), согласие на обработку ПД со ссылкой на `privacy.html` (обязательно), скрытое поле-ловушка для ботов.
- Кнопки пакетов в секции цен предзаполняют чип в форме и скроллят к ней.
- Отправка: `fetch('/api/lead', POST JSON)`. `api/lead.js` валидирует поля, отбрасывает заполненную ловушку, отправляет сообщение через Telegram Bot API (`TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` — env-переменные Vercel).
- Состояния: отправка (кнопка заблокирована), успех (сообщение + сброс формы), ошибка/бот не настроен/открыто через `file://` → сообщение со ссылкой «Напишите мне в Telegram» из конфига.
- Если в конфиге задан `metrikaId` — подключается Яндекс.Метрика, успешная заявка шлёт цель `lead`.

## 6. SEO и доступность собственного сайта

- Title/description, Open Graph (+ `og.jpg`), canonical, `lang="ru"`, schema.org `ProfessionalService` (+ `offers` по пакетам), `robots.txt`, `sitemap.xml` (URL из заглушки, заменяется при деплое).
- Семантика: `header/nav/main/section/footer`, один H1, иерархия заголовков.
- Доступность: видимый `:focus-visible`, контраст AA, alt у изображений, модалка с `role="dialog"`, закрытием по Esc и возвратом фокуса, `aria-expanded` у бургера и FAQ.
- Производительность: без фреймворков, скриншоты JPEG ≤ ~150 КБ с `loading="lazy"` (кроме hero), JS без зависимостей.

## 7. Проверка

- Локальный статический сервер, просмотр в браузере на 1440 / 768 / 375.
- Консоль без ошибок; работают меню, фильтр, модалка (в т.ч. Esc), FAQ, предзаполнение пакета, форма (валидация, fallback без API).
- `api/lead.js` проверяется локальным вызовом функции с подменённым `fetch`.

## 8. Вне рамок

CMS, блог, мультиязычность, переключатель темы, блок реальных отзывов (добавится после первых клиентов), покупка домена и деплой (только после подтверждения владельца).
