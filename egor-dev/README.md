# egor.dev — сайт-визитка

«Делаю сайты, которые приводят клиентов»: витрина концептов, три пакета, форма заявки с отправкой в Telegram.
Чистые HTML/CSS/JS без сборки, заявки обрабатывает функция Vercel `api/lead.js`.

## Запуск

```bash
npm run dev    # http://localhost:5173 — сайт + /api/lead
npm test       # тесты логики заявки и функции
```

Нужен Node 22+. Зависимостей нет.

## Что поменять перед публикацией

| Что | Где |
|---|---|
| Telegram, телефон, email | `js/config.js` — подставятся во все блоки |
| Номер счётчика Яндекс.Метрики | `js/config.js` → `metrikaId` |
| Адрес сайта (сейчас `https://egor-dev.vercel.app`) | `js/config.js`, `index.html` (canonical, og:url, og:image, JSON-LD), `robots.txt`, `sitemap.xml` |
| ФИО и статус оператора данных | `privacy.html` — `[ФИО полностью]`, `[статус]` |
| Цены и состав пакетов | `index.html`, секция `#prices` + FAQ + JSON-LD в `<head>` |
| Работы и страницы проектов | `js/cases.js` (описание, палитра, шрифты, результат) + картинки `assets/img/cases/<id>-card.jpg / -desktop.jpg / -mobile.jpg` |
| Дополнения к пакетам и их цены | `js/addons.js` |

## Заявки в Telegram

1. В Telegram откройте @BotFather → `/newbot` → получите токен.
2. Напишите своему боту любое сообщение, затем откройте `https://api.telegram.org/bot<ТОКЕН>/getUpdates` — в ответе найдите `"chat":{"id": ...}`.
3. На Vercel: Project → Settings → Environment Variables → добавьте `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`, затем передеплойте.
4. Локально — создайте файл `.env` (он в `.gitignore`):
   ```
   TELEGRAM_BOT_TOKEN=...
   TELEGRAM_CHAT_ID=...
   ```

Пока бот не настроен, форма показывает посетителю ссылку «Напишите мне в Telegram» — заявка не теряется молча.

## Деплой

Импортируйте репозиторий в Vercel (Framework Preset: Other, без команды сборки) или выполните `vercel` в папке проекта.
Папки `docs`, `tests`, `scripts` не публикуются (`.vercelignore`).

## Важно

- **Юридическое.** `privacy.html` — шаблон. Сайт собирает имя и телефон, поэтому по 152-ФЗ нужны политика, согласие (уже есть в форме) и, как правило, уведомление Роскомнадзора об обработке персональных данных. Покажите текст юристу.
- **Хостинг.** По правилам Vercel бесплатный тариф Hobby — для некоммерческих проектов. Сайт, который продаёт услуги, формально требует Pro или другого хостинга — проверьте актуальные условия.
- **Честность.** Работы подписаны «Концепт», отзывов и цифр результатов на сайте нет. Когда появятся реальные клиенты и отзывы — добавьте их; выдуманные отзывы и гарантии позиций подрывают доверие и могут нарушать закон о рекламе.
